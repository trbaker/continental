# continental

https://trbaker.github.io/continental/

Continental is a free, browser-based world strategy game that turns the classic territory-conquest formula into a geography workout for middle and high school students. Played on a live ArcGIS world map with real country boundaries, students claim 40 territories across six continents, place reinforcements, resolve attacks with dice, and fortify their borders — all while absorbing where countries actually sit, which nations share borders, and how sea routes connect distant regions like Brazil and Nigeria. Up to four students play per match from their own devices using a simple 4-letter game code, and any number of matches can run simultaneously, so a whole class (or grade) can play at once; a pass-and-play mode also supports single-device or projector play. Continent control bonuses reward strategic thinking about regional geography, a built-in how-to-play guide gets students started in minutes with no accounts or installs required, and a typical game fits comfortably within a class period.
